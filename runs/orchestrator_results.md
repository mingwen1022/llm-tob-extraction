# Orchestrator 端到端结果 — Phase E

架构：文本 → 路由(Ollama零样本判类) → 选adapter+schema → PEFT多adapter切换抽取 → 标准化JSON
一个基座(Qwen3.5-4B)常驻 + 两个 LoRA adapter(cord/duee_fin) 同时加载，按需 set_adapter() 切换。

路由开销仅占总延迟~6%，可忽略。

## 关键工程验证
1. 路由不用训练分类器 —— 用基座零样本判类即可达到100%准确率，可扩展到更多域
2. PEFT原生支持多adapter同时加载 + set_adapter()切换，本质与vLLM `--enable-lora`多LoRA服务同一概念
3. 对外只暴露一个统一入口，内部自动路由到正确的领域专家adapter —— 这是orchestrator产品价值的核心
