方案③ 从零预训练 0.1–0.3B 中文小模型

自建 tokenizer → 预训练 → SFT 全流程。这就是简历里的 "full train"，面试稀缺度极高。

难度 ★★★★☆ 成本 $20–40 算力 GCP A100 spot 必需 toB 价值 ★★☆☆☆ 工期 7–12 天
定位说明
这个项目直接 toB 业务价值弱，但它证明你「懂底层、能从零造模型」—— 绝大多数候选人只会调 API。 建议作为第二旗舰项目，和方案①（toB 应用）一应用一原理搭配，简历叙事最完整。

一句话定位

不用任何预训练权重，从随机初始化开始，训练一个约 0.1–0.3B 参数的中文 LLM，让它能进行基础中文对话。参考成熟开源路线即可，不必从头写框架。

为什么对求职有说服力

  • 能讲清 LLM 内部机制：tokenizer、attention、预训练目标、scaling、采样
  • 展示完整训练工程：数据清洗、分布式/混合精度、loss 曲线、checkpoint、PPL
  • 面试区分度极高：「我从零训过一个能说话的模型」在候选人里非常稀缺
  • 可延伸：在自己预训的模型上再做 SFT，形成"全自研"闭环

数据来源

数据说明
中文维基百科高质量、干净，适合小模型预训练主体
SkyPile / 悟道 子集大规模中文语料，采样几个 GB 即可（小模型吃不下太多）
SFT：Alpaca-zh / BELLE预训练后做指令微调，让模型会对话

详细实施步骤

  1. Phase 1 · 数据

    语料清洗 + 训练 tokenizer

    下载中文维基 + 采样 SkyPile，去重、过滤低质。用 sentencepiece / BPE 训练一个词表（如 32k）。这一步本身就是简历亮点：自建 tokenizer。

    pip install sentencepiece tokenizers datasets
# 训练 BPE tokenizer（vocab 32k）→ 把语料 tokenize 成 bin 分片
  2. Phase 2 · 配置

    定模型规模与超参

    设定 ~0.2B：如 hidden=768, layers=12–16, heads=12, ctx=1024。参考 MiniMind 配比，确认 token 总量 / 参数量大致符合 Chinchilla 比例。

  3. Phase 3 · 验证

    Mac/Colab 上小规模 smoke test

    先用极小数据 + 几百 step 在本地跑通，确认 loss 会下降、能保存/加载 checkpoint。绝不要直接上 GCP 调 bug。

  4. Phase 4 · 预训练

    GCP A100 正式预训练

    开 A100 spot，混合精度（bf16），开梯度累积。这是本作品集唯一必须烧硬算力的一步，预算约 $20–40。

    # 关键：设自动关机 + 定期存 checkpoint 到 GCS，防 spot 被抢
# 记录 loss / lr / PPL 曲线（wandb 或 tensorboard）

    ~0.2B 模型在 A100 上几小时～十几小时可训到能成句，足够展示。

  5. Phase 5 · SFT

    指令微调让它会对话

    在预训练 checkpoint 上用 Alpaca-zh / BELLE 做 SFT（可回 Mac MLX 或 Colab 做，省 GCP）。得到能问答的版本。

  6. Phase 6 · 交付

    评测 + Demo + 文案

    报验证集 PPL + 几个对话样例（坦诚展示小模型能力边界，反而显成熟）。Gradio demo + HF 上传模型与 model card。

评测与呈现

指标展示什么
验证集 PPL（困惑度）预训练是否收敛
loss / lr 曲线训练过程工程能力
对话样例SFT 后的实际效果（含 limitation 讨论）
训练成本 / token 数资源意识、scaling 理解
