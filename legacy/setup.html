二、Mac 本地环境（MLX 路线）

Apple 官方机器学习框架 MLX-LM 是 Mac 上微调/推理的正路，专为统一内存优化。

# 建议用 conda / uv 建独立环境（Python 3.11）
conda create -n llm python=3.11 -y && conda activate llm

# Mac 微调 / 推理核心
pip install mlx-lm

# 数据处理 & 评测通用
pip install datasets pandas tqdm scikit-learn
pip install outlines        # 约束解码 (方案①④)
pip install openai          # 调大模型造数据 (方案①②④)

# 本地推理 / 量化部署 / demo
brew install llama.cpp      # GGUF 量化 + 服务化
pip install gradio          # demo 页面
MLX 三个核心命令（贯穿所有 LoRA 项目）
# 1) LoRA 训练（数据放 ./data/{train,valid}.jsonl）
mlx_lm.lora --model Qwen/Qwen3-4B --train \
    --data ./data --batch-size 4 --iters 1000 \
    --adapter-path ./adapters

# 2) 把 LoRA 权重合并进基座，得到完整模型
mlx_lm.fuse --model Qwen/Qwen3-4B \
    --adapter-path ./adapters --save-path ./fused_model

# 3) 推理验证
mlx_lm.generate --model ./fused_model --prompt "..." --max-tokens 512
MLX 训练数据格式：每行一个 JSON，对话用 {"messages":[{"role":"user",...},{"role":"assistant",...}]}。

三、Colab / GCP 环境（CUDA 路线）

需要 QLoRA（省显存）或全量训练时走 CUDA。两套主流工具：

Unsloth（最省显存、最快，适合 Colab）

pip install unsloth
# 4bit QLoRA，T4 16G 就能跑 7B
# 官方 Colab 模板直接改数据即可，无需手写训练循环

LLaMA-Factory（功能全、配置式，适合 GCP 正式跑）

git clone https://github.com/hiyouga/LLaMA-Factory && cd LLaMA-Factory
pip install -e ".[torch,metrics]"
# 用 YAML 配置 SFT / LoRA / DPO / 全量预训练，一条命令启动
llamafactory-cli train config.yaml
